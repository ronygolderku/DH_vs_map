# Virtual Sensor Map for Darwin Harbour

This project builds an interactive Leaflet map for showing the virtual sensor extraction locations used with satellite data and model assessment in Darwin Harbour.

## What the Map Shows

- Virtual sensor polygons used as satellite data extraction zones
- Monitoring site markers used for validation and comparison
- Model boundary shapefile
- Mangrove habitat context layer clipped to the model boundary
- Layer controls, search, scale bar, fullscreen mode, measurement tools, minimap, coordinate readout, and polygon labels

## Main Script

Run the map from:

```r
source("map.R")
```

The script writes:

- `index.html`
- `map_files/`
- `mangroves_model_boundary_simplified_15m.rds`

Commit `index.html` and `map_files/` if you want to publish the map with GitHub Pages. The `.rds` cache is generated locally and ignored by Git.

## Required R Packages

```r
install.packages(c(
  "sf",
  "leaflet",
  "leaflet.extras",
  "htmltools",
  "htmlwidgets"
))
```
